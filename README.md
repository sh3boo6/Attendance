# نظام التحضير

تطبيق ويب (PWA) عربي بالكامل (RTL) لتحضير المشاركين في البرامج التدريبية وإصدار تقرير استحقاق الشهادات. يعمل بدون إنترنت، وتُحفظ البيانات على جهاز المستخدم فقط.

## المزايا

- إعداد برنامج تدريبي: الاسم، عدد الأيام (1–5)، الجلسات اليومية (1–3)، واستيراد المشاركين من Excel.
- تحضير كل جلسة (حاضر / غائب) مع بحث بالاسم أو رقم الهوية، وترقيم صفحات.
- تقرير الاستحقاق: نسبة الحضور لكل مشارك، ويستحق الشهادة من بلغت نسبته **80% فأكثر**.
- تصدير ملف Excel بالمستحقين فقط.
- حفظ تلقائي في LocalStorage، وحفظ/فتح نسخة احتياطية من القائمة «ملف».
- قابل للتثبيت كتطبيق، ووضع فاتح/داكن.

## صيغة ملف Excel

أول ورقة في الملف، بالأعمدة: `الاسم` · `رقم الهوية` · `المدرسة أو جهة العمل`.
يمكن تنزيل نموذج جاهز من صفحة الإعداد.

## التقنيات

Nuxt 4 (SPA) · Nuxt UI 4 · Tailwind CSS 4 · `@vite-pwa/nuxt` · SheetJS (`xlsx`) · TanStack Table

## التشغيل محلياً

```bash
pnpm install
pnpm dev
```

| الأمر | الوظيفة |
|---|---|
| `pnpm dev` | خادم التطوير |
| `pnpm build` (= `pnpm generate`) | توليد موقع ثابت للنشر في `.output/public`. **هذا الأمر هو المطلوب للعمل بدون إنترنت** لأنه يولّد صفحات HTML التي تخزّنها خدمة PWA |
| `pnpm preview` | معاينة نسخة الإنتاج (يلزم لتجربة خدمة PWA كاملة) |
| `pnpm lint` / `pnpm lint:fix` | فحص الكود وإصلاحه |
| `pnpm typecheck` | فحص الأنواع |
| `pnpm test` | الاختبارات (حساب الاستحقاق وقراءة Excel) |

## هيكل المشروع

```
app/
  components/    مكوّنات الواجهة (الهيدر، الفوتر، قائمة الملف…)
  composables/   useAttendance: حالة البرنامج والحضور
  pages/         setup · attendance · report
  plugins/       تحميل/حفظ LocalStorage
  utils/         منطق نقي قابل للاختبار (report) وExcel والتخزين
tests/           اختبارات Vitest
```

## ملاحظات

- العمل بدون إنترنت: افتح التطبيق مرة واحدة على الإنترنت (يخزّن كل ملفاته)، وبعدها يعمل بلا اتصال. يتطلب HTTPS ونسخة إنتاج، وأمر النشر هو `pnpm build` (توليد ثابت).
- البيانات محلية في المتصفح؛ احفظ نسخة احتياطية من «ملف ← حفظ» قبل مسح بيانات المتصفح.
